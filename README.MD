# Medicine Shop Backend

This is the **backend** of the Medicine Shop web application. It is built using **Express.js**, **MongoDB**, and **JWT authentication**. It provides APIs for managing medicines, users, orders, and community feedback.

## Features

- User registration and login with JWT authentication.
- CRUD operations for medicines.
- Customer cart management.
- Community feedback management.
- Fake payment simulation endpoints.

## Technologies Used

- [Node.js](https://nodejs.org/)
- [Express.js](https://expressjs.com/)
- [MongoDB](https://www.mongodb.com/)
- Mongoose ODM
- JSON Web Tokens (JWT) for authentication
- dotenv for environment variables
- Cors for API access
